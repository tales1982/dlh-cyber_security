PURPOSE
-------

This document describes the MedDefense Health Systems network layout,
VLAN segmentation, authorized user-to-host assignments, and server roles.
It is the authoritative reference for administrative baseline
construction.  Every threat hunting activity that requires "who is
authorized to access what" must cite this document.

ADMINISTRATIVE AUTHORIZATION MATRIX
------------------------------------

The following is the ONLY legitimate administrative flow in the
MedDefense environment.  Any administrative-tool execution that does
NOT match this matrix is, by definition, anomalous and requires
investigation.

  Source host       User account           Target hosts (servers)
  WS-ADMIN-01       MEDDEFENSE\robert.kim  SRV-DC-01, SRV-DC-02,
                                           SRV-HEALTH-DB, SRV-INS-DB,
                                           SRV-FILE-01, SRV-PATCH-01,
                                           SRV-AV-01, SRV-BACKUP-01
  WS-ADMIN-02       MEDDEFENSE\robert.kim  (failover only; see note)

No other workstation is authorized to initiate:
  - PsExec (psexec.exe, PsExec64.exe)
  - WMIC remote process creation (wmic /node:... process call create)
  - PowerShell Remoting (Enter-PSSession, Invoke-Command -ComputerName)
  - Remote scheduled task creation (schtasks /S)
  - Remote service creation (sc \\host create)

Service accounts (svc_*) are NEVER authorized to logon interactively
from a workstation host.  See reference/service_accounts.txt for the
complete service account authorization matrix.
