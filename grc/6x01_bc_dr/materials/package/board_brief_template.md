# Board Brief Template

## Program Status

State what the DR program package represents and which regulatory obligation it supports.

## Key BIA Finding

Name the highest-risk system or dependency. Explain the patient safety consequence in plain language.

## Recovery Test Result

State declared RTO, actual recovery time and main causes of the gap.

## Board Action or Budget

List items staff cannot solve without leadership decision, funding, vendor action or risk acceptance.

## Open Items

| Item | Owner Role | Due Date | Risk if Delayed |
|---|---|---|---|

## Recommended Board Resolution

The Board Risk Committee acknowledges receipt of the MedDefense DR Program Status Report dated [Date] and authorizes [specific action with resource commitment if applicable].

## Writing Rules

One page. No command syntax. No implementation detail unless it changes risk or budget.
