# HHS OCR Desk Audit Evidence Request

MedDefense Health Systems has been selected for a desk audit focused on HIPAA Security Rule implementation. Submit evidence for the following areas.

## Request 1: Security Risk Analysis

HIPAA specification: 164.308(a)(1)(ii)(A)  
Request: Documentation of the organization's security risk analysis, including methodology and scope.

## Request 2: Risk Management Plan

HIPAA specification: 164.308(a)(1)(ii)(B)  
Request: Evidence that identified risks are being addressed, with assigned ownership and target completion.

## Request 3: Workforce Security Awareness and Training

HIPAA specification: 164.308(a)(5)  
Request: Evidence of security awareness and training delivered to workforce members in the past 12 months.

## Request 4: Audit Controls

HIPAA specification: 164.312(b)  
Request: Evidence that system activity is logged and reviewed.

## Request 5: Workforce Security Procedures

HIPAA specification: 164.308(a)(3)  
Request: User access provisioning, termination, and periodic access review procedures.

## Request 6: Business Associate Agreement

HIPAA specification: 164.308(b)  
Request: Business Associate Agreement for CloudVault Medical or documentation showing no ePHI access has begun.

## Request 7: Technical Evaluation

HIPAA specification: 164.308(a)(8)  
Request: Evidence of periodic technical evaluation of security controls within the past 12 months.

## Request 8: Incident Response Procedures

HIPAA specification: 164.308(a)(6)  
Request: Incident response procedures and evidence of testing or activation in the past 24 months.
